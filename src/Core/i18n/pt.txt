tip.refresh = Passo 1. Mostrar a lista de contentores de chaves:\n  • os visíveis para o CryptoPro CSP (incluindo o token inserido);\n  • os encontrados diretamente nos Rutoken ligados.\nNão altera nada — apenas lê. É um bom ponto de partida.
tip.export = Passo 2. Extrair os contentores de todos os Rutoken ligados para a pasta de destino\n(6 ficheiros *.key por contentor). Lê a memória do token diretamente, contornando o CSP,\npor isso funciona mesmo com a exportação proibida. O token e os seus dados não são alterados.\nA chave da cópia continua não exportável — disso trata o botão «Tornar exportável».
tip.extract = Passo 3. Guardar o certificado do contentor selecionado num ficheiro .cer\n(dados públicos, extraídos normalmente através da CryptoAPI).\nÉ preciso um contentor selecionado, o token inserido e o contentor visível para o CSP.\nO p12utility precisa desse certificado para levantar a proibição de exportação.
tip.full = Tudo num clique: extrair os contentores do token → extrair os certificados →\nlevantar a proibição de exportar a chave privada (p12utility --cprepair --keyexport).\nResultado: na pasta de destino fica uma cópia do contentor com a chave exportável\n(serve para cópia de segurança, migração e conversão para PFX).\nO token original não é alterado; o header.key original da cópia fica guardado como header.key.backup.
tip.check = Verificar o contentor selecionado: a proibição de exportar a chave privada já foi levantada?\nO programa lê as permissões da chave (KP_PERMISSIONS) — a chave em si nunca é exportada.\nÉ assim que se confirma que «Tornar exportável» funcionou mesmo.
tip.install = Instalar no CryptoPro uma pasta de contentor extraída de um token (6 ficheiros *.key) —\nou seja, copiá-la para o arquivo do CSP. Depois o contentor aparece na lista e funciona\nsem o token: dele pode extrair-se o certificado e exportar para PFX.\nMudar o nome é opcional: o CryptoPro compara o nome com o conteúdo do contentor e\nnem sempre aceita uma cópia renomeada. O programa verifica o resultado e diz-lhe\nse o CSP vê realmente o contentor.
tip.pfx = Exportar o contentor selecionado para um ficheiro PKCS#12 (.pfx) — o certificado com\na chave privada, pronto para levar para outro sistema.\nÉ preciso: a proibição já levantada («Verificar a chave» mostra «exportável»)\ne o CryptoPro CSP instalado (usa-se o certmgr dele).\nA palavra-passe do .pfx será pedida à parte.
tip.logs = Abrir a pasta com os registos de trabalho do programa.\nCada arranque escreve o seu próprio ficheiro — dá jeito anexá-lo a uma pergunta\nse alguma coisa não correu bem. As palavras-passe nunca vão para o registo.
tip.help = Manual integrado: por onde começar, o que faz cada botão,\nos comandos do modo de consola e a análise dos erros habituais.\nEstá dentro do programa — não é preciso internet nem ficheiros externos.
tip.cancel = Interromper a operação em curso.\nO trabalho para no passo mais próximo: uma chamada ao token ou um utilitário\nCryptoPro em execução têm primeiro de terminar — e então o utilitário é fechado à força.\nOs ficheiros já guardados ficam onde estão.
