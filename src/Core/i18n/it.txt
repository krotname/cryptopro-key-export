tip.extractpfx = Crea un file PKCS#12 (.pfx) direttamente da un contenitore di file, senza CryptoPro CSP e senza certmgr.\nLa chiave privata viene decifrata con le primitive GOST integrate e il certificato viene preso da header.key (se non c'è, si può indicare un file .cer).\nLa chiave nel .pfx è protetta da password (3DES di PKCS#12); il certificato resta in chiaro. Attenzione: il file .pfx contiene la vostra chiave privata — conservatelo come un segreto.
Importante: CryptoPro NON importa un file simile — è pensato per OpenSSL e altri programmi non CryptoPro. Per riportare la chiave in CryptoPro usate il pulsante «Esporta in PFX» (tramite certmgr, serve il CSP installato).
