CryptoPro Key Export — руководство
==================================================================

Программа снимает ключевой контейнер КриптоПро с токена, снимает
запрет на экспорт закрытого ключа и выгружает результат в PKCS#12
(.pfx). Предназначена для владельца собственных ключей: резервная
копия, перенос на другую машину, конвертация.

Всё нужное лежит внутри exe. Отдельно нужен только КриптоПро CSP —
это лицензионный продукт, вшить его нельзя.

Интерфейс переведён на 20 языков: выберите язык в окне или укажите
--lang <код>, например CryptoProExport.exe help --lang en
Само руководство переведено на русский и английский; остальные языки
интерфейса показывают английский текст.


1. ЧТО НУЖНО НА МАШИНЕ
------------------------------------------------------------------
  * Windows и установленный КриптоПро CSP (проверено на 5.0 R2).
  * Операциям с закрытым ключом нужна лицензия (.jws). Отпечаток
    этой машины для её получения покажет команда fingerprint.
  * Для чтения с токена — Рутокен S / Lite или JaCarta LT. Рутокен
    ЭЦП 2.0 с аппаратным неизвлекаемым ключом так выгрузить нельзя:
    ключ физически не покидает чип.
  * Установите штатный драйвер/клиент точного токена: он предоставляет
    PC/SC reader и PKCS#11-метаданные для безопасной маршрутизации.
  * Служебные утилиты скачивать не нужно: p12utility и rtCOMLite
    вшиты в программу и распаковываются сами при первом обращении.

  Проверить готовность: кнопка «Обновить список» или команда
  CryptoProExport.exe deps


2. ПОРЯДОК РАБОТЫ: КЛЮЧ ЕЩЁ НА ТОКЕНЕ
------------------------------------------------------------------
  1) Вставьте поддерживаемый токен.
  2) «Обновить список» — программа покажет контейнеры, видимые
     КриптоПро, и найденные на токенах.
  3) Укажите «Папку назначения» — туда лягут файлы.
  4) «Сделать экспортируемым» — один клик делает всё:
       снимает контейнеры с токена (6 файлов *.key на контейнер),
       извлекает сертификаты через CryptoAPI,
       снимает запрет на экспорт закрытого ключа.
     Исходный токен при этом не изменяется.
  5) «Проверить ключ» — убедиться, что запрет действительно снят.
  6) «Экспорт в PFX» — получить .pfx с закрытым ключом.

  PIN: укажите PIN выбранного токена. Программа подставляет заводской
  PIN сама только когда драйвер подтверждает его состояние:
  12345678 для Рутокена, 1234567890 для JaCarta LT.
  Один явно введённый PIN не отправляется нескольким ридерам: выберите
  строку APDU или tokenexport/tokenfull с точным именем ридера.


3. ПОРЯДОК РАБОТЫ: КОНТЕЙНЕР УЖЕ СНЯТ В ПАПКУ
------------------------------------------------------------------
  Токен не нужен, если папка с шестью *.key уже есть.

  1) «Установить в КриптоПро» — выберите папку контейнера.
     Программа скопирует его в хранилище CSP и проверит, что
     КриптоПро контейнер увидел.
  2) «Обновить список» — контейнер появится в перечне.
  3) «Извлечь сертификат», затем «Сделать экспортируемым».
  4) «Проверить ключ» и «Экспорт в PFX».

  Про имя контейнера: КриптоПро сверяет имя с содержимым, поэтому
  переименовать копию удаётся не всегда. Если не вышло, программа
  вернёт исходное имя и напишет об этом — контейнер останется
  рабочим.


4. КНОПКИ
------------------------------------------------------------------
  Обновить список         показать контейнеры (CSP + токены)
  Экспорт с токена        снять контейнеры на диск, без снятия запрета
  Извлечь сертификат      сохранить .cer выбранного контейнера
  Сделать экспортируемым  весь цикл в один клик
  Проверить ключ          снят ли запрет на экспорт
  Установить в КриптоПро  положить снятую папку в хранилище CSP
  Экспорт в PFX           выгрузить контейнер в .pfx
  Извлечь ключ (PEM)      закрытый ключ в PKCS#8/PEM, без CSP
  Собрать PFX (без CSP)   .pfx прямо из папки контейнера, для OpenSSL
  Лицензия                установить лицензию (.jws) и проверить её
  Журнал                  открыть папку с журналами работы
  Справка                 это окно

  У каждой кнопки есть всплывающая подсказка — задержите над ней
  курсор.

  Две кнопки делают .pfx, и это РАЗНЫЕ файлы. «Экспорт в PFX» идёт
  через certmgr КриптоПро — такой файл КриптоПро потом и примет
  обратно. «Собрать PFX (без CSP)» собирает файл сам, без КриптоПро,
  но КриптоПро его НЕ импортирует: он для OpenSSL и других программ.
  Если бэкап нужен для возврата ключа в КриптоПро — берите первую.


5. КОМАНДНАЯ СТРОКА
------------------------------------------------------------------
  deps                                проверить зависимости
  list                                перечислить контейнеры
  token [папка]                       диагностика токена (PKCS#11)
  extractcert <контейнер> <папка>     извлечь .cer
  checkexport <контейнер>             проверить запрет на экспорт
  export <папка> [pin]                снять контейнеры с токенов
  tokenexport <ридер> <папка> [pin]   снять с одного выбранного токена
  tokenfull <ридер> <папка> [pin]     снять выбранный токен + всё остальное
  keyexport <папка> <cert.cer> [пар]  снять запрет на экспорт
  install <папка> [имя]               установить контейнер в CSP
  installed                           показать установленные контейнеры
  uninstall <папка>                   удалить установленный контейнер
  topfx <контейнер> <файл.pfx> [пар]  выгрузить в PKCS#12
  extractkey <папка> <файл.pem> [пар] извлечь ключ в PKCS#8/PEM (без CSP)
  extractpfx <папка> <файл.pfx> <пар> собрать PKCS#12 для OpenSSL;
                                      дальше [пар-контейнера] [cert.cer]
  liteexport <ридер> <папка> [pin]     снять контейнер Lite по APDU + разбор
  full <папка> [cert.cer] [pin]       снять с токена + всё остальное
  fingerprint                         отпечаток этой машины (для лицензии)
  license [файл|status]               установить лицензию / показать статус
  help                                это руководство
  --lang <код>                        язык интерфейса и сообщений

  Коды возврата: 0 — успех, 1 — неверные аргументы, 2 — не выполнено
  по существу (нет CSP, контейнер не найден или не виден), 3 — ошибка
  выполнения.

  У checkexport код точнее: 0 — все найденные ключи экспортируемые,
  2 — в контейнере не найдено ни одного ключа, 3 — хотя бы один
  найденный ключ пока неэкспортируемый или его права не прочитались.

  У export, full и tokenfull код 2 означает «ни одного контейнера не снято».
  Частично выполненный full или tokenfull возвращает 3. У token код 2
  означает, что токен не найден либо для запрошенной папки нет сертификата.
  Скрипту стоит считать успехом только 0.

  Вывод у графического приложения виден только при перенаправлении
  в файл: CryptoProExport.exe deps > deps.txt


6. ЕСЛИ ЧТО-ТО НЕ ПОЛУЧАЕТСЯ
------------------------------------------------------------------
  «КриптоПро CSP: НЕ НАЙДЕН»
      CSP не установлен. Без него не работает ничего, кроме чтения
      файлов с токена.

  «rtCOMLite: НЕДОСТУПЕН» или «не подходит»
      Так бывает у сборок x64/arm64: вшитая библиотека 32-битная и
      грузится только в 32-битный процесс. Возьмите обычную
      портативную сборку (x86) — она работает и на x64, и на ARM64.

  «Найдено устройств: 0»
      Токен не вставлен, не установлены его драйверы или занят
      другой программой.

  Неверный PIN, PIN заблокирован
      Программа расшифровывает такие коды в текст. После нескольких
      неверных попыток PIN блокируется — нужен код разблокировки
      администратора токена.

  «ключ не найден» при проверке или экспорте
      Контейнер не виден КриптоПро: вставьте токен либо установите
      папку контейнера кнопкой «Установить в КриптоПро».

  «НЕэкспортируемый»
      Запрет ещё не снят — нажмите «Сделать экспортируемым».
      Для контейнера, снятого с токена, это делается на копии в
      папке назначения, а не на самом токене.

  Журналы каждого запуска: %LOCALAPPDATA%\CryptoProExport\logs
  Пароли в них не пишутся. Этот файл удобно приложить к вопросу.


7. БЕЗОПАСНОСТЬ
------------------------------------------------------------------
  Снятый контейнер и .pfx — это ваш закрытый ключ в открытом виде.
  Храните их как секрет: на зашифрованном носителе, с паролем на
  .pfx, и удаляйте рабочие копии, когда они больше не нужны.

  Программа предназначена для работы владельца со своими ключами.
  Исходный токен ни одна операция не изменяет.
